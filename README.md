# Our First Chapter

A single-page anniversary website for GitHub Pages.

## Local preview

Open `index.html` directly, or run a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalisation

- Replace placeholder timeline entries in `index.html`.
- Replace the letter in `index.html` when ready.
- Replace the cover/back-of-card notes in `index.html`.
- Add real photographs to `assets/images/` and update the `memories` array in `script.js`.
- Optional: add `assets/audio/our-song.mp3`. The music control remains usable only when a permitted audio file is present.
